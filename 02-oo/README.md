# Módulo 02 — Orientação a Objetos

Exercícios focados nos quatro pilares e nas boas práticas da programação orientada a objetos:
- Classes, Construtores e Invariantes
- Encapsulamento Rígido e Imutabilidade
- Composição sobre Herança
- Polimorfismo e Contratos com Interfaces
- Refatoração de Code Smells (Primitive Obsession, Feature Envy, Long Method)
- Bugfixes de Armadilhas Clássicas da JVM (`equals`/`hashCode`, vazamento de referências)
